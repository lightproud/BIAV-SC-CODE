## 二、功能全景

**信源矩阵**（约 20 个）：零配置即用四源 = Reddit（RSS + shreddit 抓取，真实赞数与热评）、Hacker News（Algolia API）、Polymarket（Gamma API，真金赔率）、GitHub（公开 API，人物模式看 PR 速率 / 星标）；免费 CLI 自动装 = arXiv、Techmeme、Digg；带钥匙解锁 = X（浏览器 cookie 或 xAI/Xquik key）、YouTube（yt-dlp 全字幕）、TikTok / Instagram / Threads / Pinterest / LinkedIn（ScrapeCreators 抓取 API）、Bluesky、StockTwits、Perplexity、Brave；**小红书**经本地 `xiaohongshu-mcp` 服务显式开启。

**运行模式**：
1. 主题研究（人物 / 公司 / 产品 / 事件，30 天硬窗口）
2. 对比模式（`X vs Y`、`--competitors` 自动发现竞品）
3. 发现模式（`--discover` 趋势扫描，三命令协议，见下节）
4. 研究库（本地 markdown 简报库 + 离线 FTS 检索 + Atom feed 发布）
5. 趋势监控（`--store` 落 SQLite + watchlist 定时跑 + Slack/webhook 推送 + 日/周摘要）
6. 内容选题队列（queue list / cover，为播客与 X 文章供题）
7. 体检（`doctor` 预检配置、`doctor --postmortem` 事后验尸每个信源）
8. 特化：`--hiring-signals` 读招聘页判方向、`--as-of` 历史回看、ELI5 模式、`--emit=html/json`

小学生比喻：它不只是一次性帮你打听消息的侦察兵，还自带记事本（研究库）、闹钟（watchlist）、待办清单（选题队列）和体检表（doctor）的一整套侦察班。

## 三、实现方式：架构解剖

**双层分工**：`SKILL.md`（2,255 行 / 222 KB 提示词契约）+ Python 确定性引擎（CLI 入口 `last30days.py` 3,613 行 / 150 KB + `scripts/lib/` 搜索-富化-渲染模块 + vendored X 搜索客户端）。引擎干确定性脏活（并行搜源、参与度打分、跨源聚类、渲染徽章与页脚），模型干判断活。

**核心哲学「你就是 Planner / 你就是 Judge」（LAW 7 / LAW 11）**：不外接任何「规划 LLM」的 API key——宿主模型自己生成 JSON 查询计划写入临时文件、`--plan` 喂给引擎；发现模式走三命令协议：引擎提名（`--nominate-only`）→ 模型逐条判分（起名 / 判垃圾 / 打值得度，`--judgments`）→ 引擎深研 → 模型写两句内容角度（`--angles`）→ 引擎定稿渲染。引擎内置的确定性启发式仅作无人值守 cron 的兜底路径。

**输出契约工程（全文件最值得研究的部分）**：正文前置 11 条 LAW（禁尾部 Sources 块 / 禁自造标题 / 禁破折号 / 禁正文小节标题 / 页脚原样透传 / 禁倾倒原始证据 / 必织入至少 2 条署名社区热评 / 分宿主的引用渲染制度等），每条 LAW 附**带日期的真实翻车案例**（如 2026-04-18 公开版 0/8 回归：同模型同内容，缺三个结构锚就连续 8 次违约）。防失效手段成体系：
- **锚点徽章**：输出第一行强制 `last30days v{VERSION} · synced {date}` 徽章，作为格式防漂移锚——没有它模型就滑回「博客体」；
- **规则前置（hoisting）**：多条规则原在 1,200 行以下，实测模型读不到就违约，全部搬进保证加载的前段；
- **发射前自检**：合成后先扫自己最后 15 行找违禁模式，找到即删再发；
- **过期克隆自检（STEP 0）**：先查自己是不是从 Claude Code marketplaces 陈旧克隆加载的，是则改读版本化缓存；
- **显式降级规则**：每条协议配失败两次后的一击式 fallback，绝不让用户空手而归；「本窗口无扎实结论」是合法一等输出，禁止编造凑数；
- **权限透明**：`--preflight` 不读 cookie 不写文件，先打印将访问的端点、将写的路径；Security & Permissions 节逐条列「做什么 / 绝不做什么」。

小学生比喻：这份 SKILL.md 不是说明书，是一部「事故记录汇编成的交规」——每条规则旁边都钉着一张真实车祸照片和日期，路口还装了强制打卡的闸机（徽章）、出门前的镜子（自检）和备用小路（降级规则）。

## 四、与银芯的同构与差异

**深度同构（银芯路线的外部印证）**：
1. 「确定性引擎 + 模型编排判断」＝银芯「白盒脊柱零 ML + `kb_*` 动态编排」同一哲学，且其「你就是 Judge、不外接 LLM key」与 silver-core-sdk 自持技术栈的思路同向；
2. 带日期事故驱动的条款＝银芯 `lessons-learned.md` 准则清单体——差别在它把 lesson 直接嵌进技能正文当执法依据；
3. 「诚实空结果」纪律＝银芯「诚实记录不粉饰」；
4. 参与度加权 + 全量 vs 展示分层意识（原始 dump 与用户面输出严格隔离）≈ 银芯 §4.1 数据层纪律。

**功能关系：互补而非替代**。银芯采集线（T1/T2）是 Morimens 垂直域的**长期全量归档**（自有 732 万条、冷热分层、可回溯审计）；last30days 是**任意话题的 30 天即时横切**，无归档野心（本地简报库仅个人留存）。银芯缺的恰是它强的（跨平台即时横切、X/TikTok/Polymarket 触角），它做不了银芯的（全量时序、完整性审计）。现有 `anysearch` 技能覆盖了其中「网页检索」一角，但无参与度加权与多平台并行。

**引入使用的三重限制**：
1. **ToS（射程外硬约束）**：其 X 浏览器 cookie 通道、Reddit shreddit 抓取、ScrapeCreators 第三方抓取 API 均属平台 ToS 灰区——银芯 §0 明示「公开定位不解除第三方平台 ToS 约束」。零配置四源（Reddit RSS / HN Algolia / Polymarket / GitHub 官方公开接口）风险显著更低；
2. **云容器降级**：银芯会话环境无浏览器 cookie、无各家 key，装了也只剩四个免费源 + WebSearch 的降级形态；且引擎要求 Python 3.12+；
3. **上下文成本**：222 KB 的 SKILL.md 每次调用约吃五六万 token——它选择「用工程手段硬扛超长契约」，与银芯 skill-authoring-standard 的精简取向相反；这套锚点体系正是为扛住超长而生，属「重装甲路线」，银芯不必学其体量、该学其装甲件。

小学生比喻：它和银芯采集线的关系，像「满城跑的快讯记者」对「守一条街三年的档案馆」——记者哪儿热闹去哪儿但不留底，档案馆只管一条街但每天都存卷；两者不抢活。而它那本 222 KB 的说明书像穿着全套盔甲上学：确实防摔，但书包太沉，银芯值得抄的是护膝的设计图，不是整套盔甲。

## 五、可借鉴清单（对 `memory/skill-authoring-standard.md` 的候选增补）

1. **事故编号入正文**：技能内的关键规则附真实翻车日期 + 现象描述，把「为什么有这条」写在条款旁（银芯 lessons 在库里，技能正文尚未普遍这样做）；
2. **关键规则前置**：长技能按「契约在上、实现在下」分层，输出格式类规则必须落在保证被读到的前段（`intel-weekly` 这类长技能可对照自查）；
3. **输出锚**：给固定骨架报告设一个必须原样出现的首行锚（版本 + 日期戳），实测能压住格式漂移；
4. **发射前自检清单**：技能末尾放「发出前扫描自己输出的违禁模式表」；
5. **显式降级规则**：每条多步协议写明「失败几次后退到哪条一击式路径」，杜绝空手而归与自由发挥；
6. **诚实空结果条款**：把「本窗口无扎实结论」定为合法输出并禁止凑数（周报风险哨兵节可显式采用）；
7. **权限预览**：涉外部访问的技能提供 preflight 式「将访问什么 / 绝不做什么」自述。
